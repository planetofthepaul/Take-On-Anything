Turn a spreadsheet into a tool, free

You built a calculator in Excel — a pricing sheet, a loan estimator, a quote builder, a unit converter — and now you want people to actually use it without sending them a file or making them install anything. This turns that spreadsheet into a working web calculator. Upload the .xlsx, and the formulas run live in the page: change an input, the results recalculate instantly, exactly like the original sheet.

Why it needs an .xlsx and not a CSV

A CSV file only stores the final values, not the formulas behind them. As soon as you save a spreadsheet as CSV, the math is gone and there is nothing left to convert. Export or save your file as Excel (.xlsx or .xlsm) so the formulas come along. If you only have a CSV, open it in Excel or Google Sheets, rebuild the formulas, and save it as .xlsx first.

How the inputs and results are detected

Any cell that contains a formula becomes a result. Any plain cell that those formulas point to becomes an input you can change. Labels are pulled from the text sitting in the cell to the left of, or directly above, each value — the same way you would read the sheet yourself. If the layout is unusual and the auto-detected form looks off, switch to Sheet view: it shows the whole grid with the input cells editable and every formula recalculating as you type.

Private by design

The file is read and calculated entirely in your browser. It is never uploaded, so your numbers and your formulas stay on your machine. That also means it works offline once the page has loaded, and there are no accounts, no watermarks, and no scan or usage limits.

What does not convert

This is an early version focused on formula-driven calculators. Macros (VBA), pivot tables, charts, and a handful of less common functions will not run, and the tool flags anything it could not convert rather than failing silently. Cross-sheet references work as long as every sheet is in the same file.
